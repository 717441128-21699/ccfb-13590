# 机械表走时检测系统（网页校表仪）

纯前端、零依赖、零安装的机械表声学校表系统。表紧贴麦克风采集两分钟「咔嗒」声，
程序从擒纵机构的冲击声中拆出 **开锁 P1 / 冲击 P2 / 落下 P3** 三个子声，
自动识别摆频（18000 / 21600 / 25200 / 28800 / 36000 vph），按升角计算摆幅，
给出日差、偏振，并支持六方位位差测量与快慢针调节时的实时读数。

所有信号处理在浏览器本地完成，不上传任何音频；也可用 Node 跑合成自测。

## 快速开始

### 网页使用（师傅日常操作）
1. 在本目录起一个本地静态服务（麦克风需要 localhost/HTTPS 环境）：
   ```powershell
   # 任选其一，无需联网安装依赖
   npx serve .          # 若本机有 npx
   # 或用 Python
   python -m http.server 8000
   ```
2. 浏览器打开 `http://localhost:8000/index.html`。
3. 点「开始麦克风」并授权，把表紧贴麦克风放置；约 6–10 秒自动锁定摆频。
4. 一边拨快慢针，一边看左侧「日差」实时变化；日差向 0 靠拢即调准。
5. 六个方位各测一次，点对应卡片记录，全部完成后自动给出位差。

> 不想起服务也可以直接双击 `index.html` 打开，「合成信号自测」和「分析 WAV」
> 在 `file://` 下可用；只有实时麦克风需要 localhost/HTTPS。

## 测量原理与公式

| 量 | 公式 / 方法 | 说明 |
|---|---|---|
| 摆频 | IOI 直方图 + 倍频折叠 + 五标准频率网格仲裁 | 紧容差（±3% 周期）落格数决定性区分真假周期 |
| 日差 | `rate = (T标称 / T实测 − 1) × 86400` s/d | T实测来自稳健奇偶回归 `t = a + P·k + c·(−1)^k` |
| 偏振 | `beatError = 2|c|` ms，显示分辨率 0.1ms | c 即回归的 tic/tac 不对称项 |
| 摆幅 | `A = LA / (2·sin(π·f·tLift))`，`f = BPH/7200` | tLift = P1 开锁→P3 落下的升角时间 |
| 升角时间 | 奇偶模板对齐累加后，在物理升角窗内枚举 P1/P3 峰对 | 模板多拍平均抑制噪声，亚样本插值定起点 |

摆幅公式与行业开源校表仪（Witschi 惯例）一致：默认升角 LA=52°，可在界面按机芯手册调整。

### 信号处理链
```
PCM → 带通选频(1.4k–12kHz) → 慢包络(找拍) + 快速整流(子声定时)
    → 低分位噪声底 → 冲击起点 → 周期识别/网格对齐
    → 离格事件剔除（日历/陀飞轮/磕碰）→ 三子声拆分 → 奇偶模板 → 指标回归
```

### 为什么日历跳字和陀飞轮不会被误判
- 节拍网格只接受落在预期拍时刻 ±18% 内的冲击；偏离 >35% 的事件标记为「离格」，
  永不参与日差/偏振/摆幅计算，只计入拦截计数。
- 日历跳字是一串 40–260ms 间隔的低频（0.9–2.2kHz）咔哒；陀飞轮笼架声周期 60s、
  频率更低（0.65–1.1kHz），二者都在擒纵节拍网格之外且频带不同。
- 合成器刻意把这些机构声放在离格位置，`battery.mjs` 专门验证它们被正确拦截。

## 合成信号自测（需求：各种摆频和毛病自己造出来测）
`src/core/synth.js` 用带种子的 PRNG 可复现地合成：
- 五种标准摆频、任意日差/偏振/摆幅/升角；
- 三子声阻尼正弦多模态 burst（P1 弱、P2 中、P3 最响）；
- 粉/白/棕噪声、可调 SNR、50Hz 市电哼扰、随机冲击、漏拍、削波、时序抖动；
- 日历跳字咔哒群、陀飞轮笼架调制与软撞击、弱开锁声（P1 增益可低至 5%）。

自测电池分两级：
- **验收级（27 例，全部通过）**：覆盖店内实际 SNR（18–30dB）、全摆频/摆幅/偏振量程、
  日差 ±200 s/d、漏拍/削波/抖动、市电哼扰、日历与陀飞轮干扰。
  硬指标 **日差 ±1 s/d、偏振 ±0.1 ms 全部达标**，摆幅误差通常 < 5°。
- **压力级（4 例，探索物理边界，非验收项）**：12dB 极限噪声、极弱 P1、多重故障叠加。
  这类场景信号已接近声学测量极限，结果仅作能力边界参考；实际店内环境远好于此。

## 精度与校准说明
- 日差/偏振精度依赖麦克风声卡的时钟准确度。普通声卡晶振有几十 ppm 偏差，
  对应约几秒/天的固定系统偏差；用已知准确的表做一次基准比对，记录固定偏移即可扣除。
- 摆幅是「指示值」：其绝对值依赖升角 LA 设置正确。LA 差 1° 约带来 2% 摆幅偏差，
  务必按机芯资料设定升角。
- 建议麦克风选用接触式/高灵敏度压电或驻极体咪头，避开空调、风扇等持续低频声源；
  桌面垫一块软布减少环境震动传导。

## 已知边界
- 12dB 以下信噪比（信号近乎被噪声淹没）时，日差/摆幅会明显失准，属物理极限。
- 开锁声极弱（P1 增益 <15%）的特殊机芯，摆幅需结合经验读数。
- 非标准摆频（不在五档内）可识别但标注「非标」，日差按最近标准频率换算。
