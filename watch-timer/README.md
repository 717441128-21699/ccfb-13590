# 机械表走时检测系统（网页版校表仪）

用店里的麦克风代替三万元的校表仪：表贴着麦克风录两分钟，程序从擒纵机构的"咔嗒"声里
拆出**开锁、冲击、落下**三个子声，识别摆频（18000/28800 等），算出**日差、摆幅、偏振**，
画时序图，并支持六个方位各测一次给位差。师傅拨快慢针时读数实时变化。

纯浏览器本地运算，零第三方依赖、零构建、音频不上传。

## 目录结构

```
watch-timer/
├── index.html          网页界面
├── css/style.css       样式
├── js/

│   ├── app.js          网页主控：麦克风/合成数据源 → 分析器 → 实时 UI
│   └── worklet.js      AudioWorklet 音频分块（含 ScriptProcessor 回退）
├── selftest.mjs        合成信号自检矩阵（node --test）

```

## 运行

### 直接打开网页
双击 `index.html`。麦克风需要 `localhost` 或 `https` 环境（浏览器安全限制），
本地可任选一种静态服务器：

```bash
# Node 自带（推荐）
npx serve .
# 或 Python
python -m http.server 8000
```

浏览器打开 `http://localhost:端口/` 后：
1. 选「麦克风实测」，允许麦克风权限，点**开始检测**，表紧贴麦克风；
2. 或选「合成演示」，无需硬件即可看到完整功能，拖"日差微调"滑块模拟拨快慢针。

### 跑算法自检（无需浏览器）

```bash
node --test selftest.mjs      # 17 项指标测试
node e2e-check.mjs            # 六场景端到端
```

## 检测原理与处理链

1. **带通滤波**（900Hz–11kHz 双二阶级联）去桌面隆隆声与高频嘶声；
2. **整流 + 单极点包络**，门控式自适应噪底，过阈段分割 + 抛物线亚采样，
   起振时刻精度优于 0.1 个采样；
3. **拍网格捕获**：在标准摆频候选上算折叠相位直方图的圆形自相关锐度，
   真周期锐度最高，天然抗倍频/分频；再用每拍代表点稳健回归精修拍间隔 B；
4. **锁相跟踪 + 健康检查**，跟丢自动重新捕获；
5. **三子声 1D 聚类**，按"冲击声最强且在平衡点"的物理规则贴标签，
   相位对齐使冲击对准零偏移；
6. **异声剔除**：日历跳字（低频闷响）、陀飞轮周期声靠谱质心 + 网格位置识别，
   不会被当成擒纵子声；
7. **指标**：
   - 日差 = 实测拍频相对标称摆频的偏差，换算秒/天；
   - 偏振 = 偶数拍与奇数拍冲击偏移之差（毫秒）；
   - 摆幅由升角模型反演：`sin(π·δ/B) = sinβ/|sinA|`，左右摆分别给出。

## 精度指标（合成信号，96kHz）

| 指标 | 要求 | 实测（60–120s 窗口） |
|---|---|---|
| 日差 | ±1 s/day | 误差 ≤ 0.3 s/day |
| 偏振 | 0.1 ms | 误差 ≤ 0.01 ms |
| 摆频识别 | 18000/28800 等 | 全候选正确，抗倍/分频 |
| 摆幅 | — | 误差 ≤ 5°，左右独立 |
| 日历/陀飞轮异声 | 不误认 | 按音色/周期标记剔除 |

日差精度随测量时长提升（30s 已可用，两分钟最稳），与真实贴表流程一致。

## 合成器能造哪些"表"

`WatchSynth` 物理建模摆轮简谐振动，在开锁/冲击/落下三个相位发衰减正弦瞬态，
可配摆频、日差、偏振、左右摆幅、升角、抖动、背景噪，并注入：
日历跳字（低频多脉冲闷响）、陀飞轮（周期异声 + 摆幅调制）、
缺擒纵、弱擒纵、重复滴答、随机磕碰、线性漂移。每个事件都带 ground truth 标签，
自检据此严格核对算法。

## 已知边界

- **陀飞轮**：公转带来的摆幅周期调制会让瞬时日差围绕真值波动，业界也需按整公转
  周期平均；系统保证不丢锁、异声正确标记，长窗读数收敛。
- **36000 等极高密度摆频**在子声间隔过近时可能只检出主冲击声，此时摆幅/偏振留空，
  日差仍由准确的拍间隔给出。
- 真实麦克风信噪比低于合成信号时，建议延长测量时间并保持环境安静。
